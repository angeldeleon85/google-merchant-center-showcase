# Google Merchant Center Marketplace Showcase

Professional Google Merchant Center / Google Shopping feed optimization project covering product structured data and marketplace readiness.

## Capabilities Covered

- Product data feed QA
- Required and recommended Merchant Center attributes
- GTIN/MPN/brand data quality checks
- Price and availability consistency
- Product structured data alignment
- Shipping and return policy checks
- Promotions feed planning
- Disapproval triage and remediation workflow

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
